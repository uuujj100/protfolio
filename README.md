# NIGHT7 LAB · 技术作品集

2026 级人工智能专业学生的个人技术作品集页面。纯静态，零依赖，单文件即可运行。

## 内容

| 模块 | 说明 | 涉及技术 |
| --- | --- | --- |
| N7 Player · 视频播放模块 | 倍速、进度记忆、断点续播；大文件分片预读解决首帧卡顿 | HTML5 Video API、事件驱动、本地状态缓存 |
| GeoMock · 定位服务 Demo | 权限申请、位置回调、坐标数据回传全链路跑通 | Android Location、Web Geolocation、坐标系转换 |
| 站点部署与发布 | 域名解析、Nginx 反向代理、HTTPS 证书；后迁移 GitHub Pages | DNS、Nginx、ACME、GitHub Pages |

## 本地运行

下载 `index.html`，双击用浏览器打开即可，不需要安装任何依赖。

## 部署

推到 GitHub 仓库后，在 **Settings → Pages** 里选择 `main` 分支的根目录，等待约 1 分钟，
访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。
